# Uploading the External Source & Event Type Schema
First, we must upload the schema we created for the External Source Type & the two External Event Types. In the Aerie UI, navigate to the External Sources page:

<figure>
  <img alt="Click 'External Sources' button" src={externalEventsTutorialUploadStep1} />
</figure>

Next, click the `Types` button in the top-right to switch to the sub-page used for creating & managing External Source & Event Types.

<figure>
  <img alt="External Type Manager" src={externalTypeManager} />
</figure>

Click `Choose File` and select the `External_Types_Schema.json` file we previously created. The new Source Type & the two Event Types should have their names shown on the left-panel.

<figure>
  <img alt="Results from successfully parsing the file" src={externalTypeManagerFileParsed} />
</figure>

Clicking `Upload` will create the listed types.

<figure>
  <img alt="External Source type created" src={externalTypeManagerSuccessfulUpload} />
</figure>

# Uploading the External Source
Having created our types, we are now able to upload the External Source. Navigate to the External Sources page by clicking the `Sources` button in the top-right:

<figure>
  <img alt="External Source Manager" src={externalSourceManager} />
</figure>

We can now upload our new External Sources. Click the `Browse...` button, and select the first file, `External_Events_Demo_00.json`. The upload section will autofill as follows:

<figure>
  <img alt="Click the 'Browse...' button and select the first test file - uploaded file form will become populated" src={externalEventsTutorialUploadStep2} />
  <figcaption><i>Auto-populated uploaded file form</i></figcaption>
</figure>

The `Derivation Group` field allows you to change the Derivation Group that the source will associate with, for this tutorial we will leave it as `DemoType Default`.

:::info Note

For more information on Derivation Groups, refer to the [External Events](../../../planning/external-events/introduction/#derivation) documentation.

:::

Finally, click upload. The new External Source is visible in the table on the right:

<figure>
  <img alt="External Sources table is populated" src={externalEventsTutorialUploadStep3} />
</figure>

Click the `X` next to `Selected External Source` to deselect it, then repeat these steps with the second file. The table should now look as follows:

<figure>
  <img alt="External Sources table is populated with both test files" src={externalEventsTutorialUploadStep4} />
</figure>

We can now see both external sources we've uploaded in the top-right table, and the external events of the selected source (in this case, the second example file since we just uploaded it) in the bottom-right table.

We are now ready to associate our new Derivation Group (`DemoType Default`) with a plan!
