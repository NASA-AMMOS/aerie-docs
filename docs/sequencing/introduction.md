# Sequencing

Aerie's Phoenix editor provides a sequence development environment within Aerie. Author sequences and adapt Aerie to fit your needs:

- Start using Phoenix out of the box with the [SeqN](/aerie-docs/sequencing/seqn) authoring language and the [SeqJSON](https://github.com/NASA-AMMOS/seq-json-schema) interchange format.
- Leverage the [editor adaptation](/aerie-docs/sequencing/adaptation) to configure additional languages or implement support for your own.
- Use [Aerie Actions](/aerie-docs/sequencing/actions) for external integrations.
